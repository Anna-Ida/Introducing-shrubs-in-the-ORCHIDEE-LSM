This repository contains the code used for the analysis in the publication: Kirchner, A., López-Blanco, E., Bastrikov, V., Luyssaert, S., Peylin, P., and Lansø, A. S.: Introducing shrubs enhances the representation of high-latitude vegetation and carbon cycling in the ORCHIDEE land surface model, EGUsphere [preprint], https://doi.org/10.5194/egusphere-2026-1071, 2026.


The jupyter notebook file anaylsis.ipynb contains code to load output data produced with ORCHDEE and analyse it, in comparison with observational data described in the manuscript, and produce the figures contained in the publication.
